# Token Tracker

- Локальный монитор Codex; Python standard library, без запросов к моделям и без чтения auth.json.
- Название десктопного чата: непустое threads.name, затем threads.title. База Codex всегда открывается read-only.
- Процент аккаунта из rate_limits — наблюдение. Распределение по чатам/моделям — условная оценка, а не официальное списание.
- Кредитные тарифы не являются подтверждённой формулой недельной подписки. Не выдавать сравнительный график кредитов за график фактического расхода лимита.
- Распределять расход глобально, затем фильтровать. Фильтр не должен перенормировать чужие затраты на выбранный чат.
- Сохранять корректный учёт кеша, reasoning, форков, reset и подагентов. Нет данных не означает ноль.
- Перед изменением алгоритма выполнить python -m unittest -v tests.test_monitor tests.test_quota.
- Рабочие данные в data/; не добавлять их в Git. После изменений UI перезагрузить страницу, после изменений Python перезапустить монитор.
- После завершения задачи и необходимых проверок обязательно закоммитить свои изменения и выполнить git push в текущую ветку. Не включать в коммит посторонние незавершённые изменения. Если коммит или push не удался, явно сообщить причину в итоговом ответе.
- При изменении функциональности, интерфейса или запуска обновлять README.md и README.ru.md, чтобы документация на GitHub соответствовала текущей версии. После завершённых изменений приложения обновлять GitHub-релиз: описание изменений и скачиваемые сборки должны соответствовать опубликованному коду. Если обновление документации или релиза не удалось, явно сообщить причину в итоговом ответе.
